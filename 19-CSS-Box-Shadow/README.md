# Day 19 – CSS Box Shadow

## Overview
CSS box-shadow property adds shadow effects around elements, creating depth and visual interest. This project demonstrates various shadow techniques for modern UI design.

## Concepts Covered
- Shadow syntax: `box-shadow: offset-x offset-y blur-radius spread-radius color`
- Blur and spread: Controlling shadow softness and size
- Multiple shadows: Layering multiple shadows for complex effects
- Inset shadows: Creating inner shadows for neumorphism

## Learning Outcomes
- Understand box-shadow property syntax and parameters
- Create different shadow effects for various UI elements
- Apply shadows for depth, focus, and modern design trends

## Practice Description
This project showcases five different box-shadow techniques: simple drop shadows, multiple layered shadows, interactive hover effects, glowing shadows, and neumorphic design. Each card demonstrates a unique shadow style.

## How to run
Open the `index.html` file in any modern web browser to view the shadow effects. Hover over the button in the "Hover Effect" card to see the interactive shadow.
