# Day 21 – Responsive Design

## Overview
Responsive design is crucial in modern web development as it ensures websites look and function well on all devices, from mobile phones to desktop computers. This project demonstrates a mobile-first approach to responsive design, starting with styles optimized for small screens and progressively enhancing for larger devices using media queries.

## Concepts Covered
- **Media queries**: CSS rules that apply styles based on device characteristics like screen width
- **Mobile-first design**: Designing for mobile devices first, then adding enhancements for larger screens

## Learning Outcomes
- Understanding how to create layouts that adapt to different screen sizes
- Implementing mobile-first responsive design principles
- Using media queries effectively to create breakpoints for tablet and desktop views

## How to run
Open the `index.html` file in a web browser. Resize the browser window or use developer tools to simulate different device sizes and see the responsive behavior in action.
