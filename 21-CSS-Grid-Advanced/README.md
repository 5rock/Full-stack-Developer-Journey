# Day 21 – CSS Grid Advanced

## Overview
This example demonstrates advanced CSS Grid techniques for building complex, modern UI layouts. It includes multiple rows and columns, named grid-template-areas, and responsive behaviour using media queries.

## Concepts Covered
- `grid-template-areas`
- `auto-fit` / `auto-fill` (theory and practice in responsive layout patterns)
- Responsive grids using breakpoints

## Learning Outcomes
- Create a multi-area grid layout
- Use named grid areas for clear layout semantics
- Adjust complex grid templates for x-large, desktop, and mobile views

## How to run
Open `index.html` in a modern browser. Resize the window to see layout recompute between desktop/tablet/mobile breakpoints.
