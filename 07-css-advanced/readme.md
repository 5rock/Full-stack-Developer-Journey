📘 Day 7 – CSS Box Model Practice
📌 Overview

Day 7 focuses on understanding and practicing the CSS Box Model, one of the most important core concepts in CSS.
The goal of this practice is to clearly understand how content, padding, border, and margin work together to control layout and spacing on a webpage.
