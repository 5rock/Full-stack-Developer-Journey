# Day 24 – Portfolio UI

## Overview
This is a personal portfolio website template designed to showcase a developer's work, skills, and contact information. The layout is clean, modern, and fully responsive, making it suitable for professionals in tech fields.

## Sections Breakdown

### Hero/About Section
- Personal introduction with name, title, and brief description
- Professional headshot placeholder
- Call-to-action buttons linking to projects and contact

### Projects Section
- Grid layout displaying project cards
- Each card includes project image, title, description, tech stack tags, and links
- Hover effects for better interactivity

### Skills Section
- Categorized skills (Frontend, Design, etc.)
- Progress bars showing proficiency levels
- Clean visual representation of technical abilities

### Contact Section
- Contact information and social media links
- Contact form for potential clients/employers
- Professional presentation of contact details

## Customization Guide

### Personal Information
1. Update the name in the header logo and hero section
2. Replace placeholder images with actual photos
3. Modify the bio text in the hero section
4. Update contact details in the contact section

### Projects
1. Replace placeholder project images
2. Update project titles, descriptions, and tech stacks
3. Add actual links to live demos and source code
4. Add or remove project cards as needed

### Skills
1. Modify skill categories and individual skills
2. Adjust proficiency percentages in the HTML style attributes
3. Add new skill categories if needed

### Styling
1. Update color scheme by modifying CSS custom properties
2. Adjust typography by changing font-family values
3. Modify spacing and layout by updating padding/margin values
4. Customize hover effects and transitions

### Content Tips
- Keep descriptions concise and impactful
- Use high-quality images for projects
- Ensure all links are working and up-to-date
- Regularly update skills and projects as you learn and build
