# Day 25 – CSS Mini Project

## Project Explanation
This mini project is a product showcase website for a fictional tech gadgets store called "TechGadgets". The site demonstrates a complete e-commerce style layout with product listings, features, and a newsletter signup. The project showcases the practical application of both CSS Flexbox and Grid layout systems in a real-world scenario.

## Concepts Used
- **CSS Grid**: Used for the products grid layout and footer sections for two-dimensional control
- **Flexbox**: Used for navigation, feature items, and newsletter form for one-dimensional layouts
- **Responsive Design**: Mobile-first approach with media queries for tablet and desktop breakpoints
- **Modern CSS**: Custom properties, transitions, and modern layout techniques

## Key Learnings
- When to choose Grid vs Flexbox: Grid for complex 2D layouts, Flexbox for simpler 1D arrangements
- Combining layout systems: Using both Grid and Flexbox in the same project for optimal results
- Responsive patterns: Creating flexible layouts that work across all device sizes
- Component-based thinking: Building reusable UI patterns that can be applied consistently
- Performance considerations: Efficient CSS that loads quickly and renders smoothly
