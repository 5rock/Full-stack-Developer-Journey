📘 CSS Float, Clear & Overflow Practice

📌 Overview


This project demonstrates classic CSS layout techniques using the float, clear, and overflow properties.
The goal is to understand how older layout methods work and how they control element positioning, text wrapping, and content overflow.

🛠️ Technologies Used

HTML5

CSS3

🎯 Concepts Covered
🔹 CSS Float

Used to align images and elements to the left or right

Allows text to wrap around floated elements

.float-img {
    float: left;
}


Use case: Text wrapping around images.

🔹 CSS Clear

Prevents elements from wrapping around floated elements

Ensures layout separation after floats

.clear-box {
    clear: both;
}


Use case: Clearing floats to restore normal document flow.

🔹 CSS Overflow

Controls how content behaves when it exceeds container size

Practiced using overflow: auto

.overflow-box {
    height: 100px;
    overflow: auto;
}


Use case: Scrollable containers and hidden overflow control.
