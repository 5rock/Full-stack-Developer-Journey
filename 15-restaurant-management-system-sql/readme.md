# 🍽️ Restaurant Management System (SQL)

## 📌 Overview
This project implements a **Restaurant Management System** using SQL.
It simulates real-world restaurant operations such as menu management,
customer orders, deliveries, and billing.

The focus is on **relational database design**, **data integrity**, and
**efficient querying**.

---

## 🛠️ Technologies Used
- SQL
- MySQL
- MySQL Workbench

---

## 🗄️ Database Features
- Multiple related tables
- Primary and foreign keys
- Data constraints
- Trigger for automatic bill calculation
- Indexes for performance optimization
- View for order summary
- Stored procedure for customer-based queries

---

## 📊 Tables Included
- Restaurants
- Menu
- Customers
- Orders
- Deliveries

---

## ⚙️ Advanced SQL Concepts Used
- Triggers (`BEFORE INSERT`)
- Views
- Stored Procedures
- Indexes
- Aggregate queries
- Joins (INNER, LEFT)

---

## 🎯 Learning Outcome
- Practical understanding of relational database design
- Hands-on experience with SQL automation using triggers
- Real-world database modeling skills
