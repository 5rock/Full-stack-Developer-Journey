# 🍽️ Restaurant Management System (SQL)

## 📌 Overview

This project implements a **Restaurant Management System** using **MySQL**, designed to simulate real-world restaurant operations such as managing menus, handling customer orders, tracking deliveries, and processing payments.

It focuses on **efficient relational database design**, ensuring **data integrity**, and demonstrating advanced SQL capabilities like automation and optimization.

---

## 🛠️ Technologies Used

* **SQL**
* **MySQL**
* **MySQL Workbench**

---

## 🗄️ Database Architecture

The system is built using a **normalized relational database structure** with well-defined relationships between entities.

### 📊 Tables Included

* **Restaurants** – Stores restaurant details
* **Menu** – Contains food items and pricing
* **Customers** – Stores customer information
* **Orders** – Tracks customer orders
* **OrderItems** – Handles multiple items per order *(advanced feature)*
* **Deliveries** – Manages delivery details
* **Payments** – Stores payment information

---

## ⚙️ Advanced SQL Concepts Used

* 🔹 **Triggers** (`BEFORE INSERT`) for automatic subtotal calculation
* 🔹 **Views** for simplified data retrieval (Order Summary)
* 🔹 **Stored Procedures** for reusable queries
* 🔹 **Indexes** for performance optimization
* 🔹 **Joins** (INNER JOIN) for relational data access
* 🔹 **Constraints** (PRIMARY KEY, FOREIGN KEY, UNIQUE, CHECK)

---

## 🔄 Key Features

* ✔ Multi-item order handling (real-world scenario)
* ✔ Automatic bill calculation using triggers
* ✔ Data consistency with foreign key constraints
* ✔ Delivery and payment tracking system
* ✔ Optimized queries using indexing

---

## 📈 Sample Functionalities

* Retrieve all orders placed by a specific customer
* View complete order summary using a single query
* Automatically calculate subtotal when items are added
* Track delivery status in real-time
