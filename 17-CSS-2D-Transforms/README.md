# Day 17 – Mastering CSS 2D Transforms

## Overview
CSS 2D transforms allow you to modify the position, size, and shape of elements in a 2D space. This project demonstrates the core transform functions with interactive hover effects.

## Concepts Covered
- `translate()`: Moves an element along the X and Y axes
- `rotate()`: Rotates an element by a specified angle
- `scale()`: Scales an element up or down
- `skew()`: Skews an element along the X and Y axes

## Learning Outcomes
- Understand how to apply 2D transforms to HTML elements
- Use transform functions individually and in combination
- Create smooth animations with CSS transitions

## Practice Description
This project features five cards, each demonstrating a different transform function. Hover over the demo boxes to see the transforms in action. The layout is responsive and uses CSS Grid for centering.

## How to run
Open the `index.html` file in any modern web browser to view the transforms. Hover over the colored boxes to see the effects.
