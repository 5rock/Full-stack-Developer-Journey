# Day 25 – CSS Position Practice

## Overview
This project demonstrates all CSS position types in a single practical layout: static, relative, absolute, fixed, and sticky. The design includes a sticky top nav, an absolute tile inside a relative container, layered components with z-index, and a fixed action button.

## Concepts
- `static`: default document flow (normal layout)
- `relative`: local coordinate for absolute children
- `absolute`: positioned relative to nearest positioned ancestor
- `fixed`: pinned to viewport (always visible while scrolling)
- `sticky`: remains fixed inside scroll container until boundaries are reached

## Learning Outcomes
- Understand the rendering and stacking contexts of position values
- Use position to build practical UI patterns
- Combine position with modern UI design (shadows, gradients, responsive spacing)

## How to run
Open `index.html` in a web browser and scroll. Observe sticky navbar and fixed “Help” button while verifying absolute and relative behavior in the content sections.
