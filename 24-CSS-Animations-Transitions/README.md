# Day 24 – CSS Animations & Transitions

## Overview
This project teaches interactive animation techniques using pure CSS. It includes button transitions, card hover animations, and keyframe-driven motion.

## Concepts
- `transition` for smooth hover/interactions
- `transform` for scale/rotate/translate
- `@keyframes` for sequence & infinite animations

## Learning Outcomes
- Build polished UI interaction states
- Use keyframes for advanced animations
- Combine transitions with animation controls for UX

## How to run
Open `index.html` in a modern browser and hover over buttons/cards. Observe keyframe dot animation and update timing in CSS for practice.
