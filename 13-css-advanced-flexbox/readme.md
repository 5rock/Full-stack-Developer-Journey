# 📘 Day 13 – Advanced CSS Flexbox

## 📌 Overview
This project focuses on **advanced Flexbox concepts** that control how flex items grow, shrink, and align independently within a flex container.

---

## 🛠️ Technologies Used
- HTML5
- CSS3

---

## 🎯 Concepts Practiced

### 📦 Advanced Flexbox Properties
- `flex-grow`
- `flex-shrink`
- `align-self`
- `gap`

---

### 📈 Flex Grow
- Allows an element to take up available free space
- Used to create flexible and responsive layouts

---

### 📉 Flex Shrink
- Controls how items shrink when space is limited
- Helps prevent layout breaking

---

### 🎯 Align Self
- Overrides `align-items` for individual flex items
- Useful for custom alignment inside a flex container

---

### 🎨 Styling Enhancements
- Centered content using Flexbox
- Clean spacing and layout
- Color variations to visually distinguish behaviors

---

## 🔧 Key CSS Features Used
- `display: flex`
- `flex-grow`
- `flex-shrink`
- `align-self`
- `gap`
- `border-radius`
