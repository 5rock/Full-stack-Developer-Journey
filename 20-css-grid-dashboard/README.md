# 20 – CSS Grid Dashboard

## Overview
CSS Grid is a two-dimensional layout system for the web that allows developers to create complex, responsive layouts with ease. Unlike Flexbox, which is primarily one-dimensional, Grid excels at handling both rows and columns simultaneously. This project demonstrates the power of CSS Grid by building a responsive dashboard layout, showcasing how Grid can be used to structure entire page layouts efficiently.

## Concepts Covered
- **Grid container**: The element that establishes a grid formatting context
- **Grid rows & columns**: Defining the structure of the grid using `grid-template-rows` and `grid-template-columns`
- **gap**: Spacing between grid items using the `gap` property

## Learning Outcomes
- Creating structured, complex layouts using CSS Grid
- Understanding the difference between Flexbox (one-dimensional) and Grid (two-dimensional) layout systems
- Implementing responsive designs that adapt to different screen sizes using Grid

## Project Description
This project is a clean, modern dashboard layout built entirely with pure HTML5 and CSS3, utilizing CSS Grid for the overall page structure. The dashboard includes a header with navigation, a sidebar menu, a main content area with widget cards, and a footer. The layout is fully responsive, adapting from a desktop layout with sidebar to a mobile-stacked layout.

## How to run
Simply open the `index.html` file in any modern web browser to view the dashboard.
