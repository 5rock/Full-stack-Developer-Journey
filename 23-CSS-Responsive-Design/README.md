# Day 23 – CSS Responsive Design

## Overview
This project showcases a fully responsive webpage built with a mobile-first approach. It uses fluid layouts, viewport units, and media queries to adapt typography and spacing across devices.

## Concepts
- Mobile-first design
- Media queries (breakpoints at 900px, 1200px)
- Fluid layouts using percentages, minmax(), and clamp()
- Responsive typography using clamp() and viewport-based scaling

## Learning Outcomes
- Create a responsive design workflow from small to large devices
- Use CSS strategies for fluid, adaptive page structure
- Implement responsive navigation, hero, feature grid, and pricing cards

## How to run
Open `index.html` in a modern browser, then resize viewport or use device emulation to verify behavior for mobile, tablet, and desktop.
