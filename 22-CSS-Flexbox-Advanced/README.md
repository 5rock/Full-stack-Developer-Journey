# Day 22 – CSS Flexbox Advanced

## Overview
This project demonstrates advanced Flexbox techniques with nested flex containers, alignment control, and responsive design. It includes a real UI example: navbar + responsive card layout.

## Concepts Covered
- Flex container properties:
  - `justify-content`
  - `align-items`
  - `flex-wrap`
- Item-level control:
  - `align-self`
  - `flex-grow`, `flex-shrink`, `flex-basis`

## Learning Outcomes
- Build responsive row and column flex layouts
- Master alignment for horizontal and vertical focus
- Use nested flex containers for real-world app UIs

## Example Use Cases
- Navbar + button bars
- Card galleries and dashboards
- Responsive form controls and toolbars
