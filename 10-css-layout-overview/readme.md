📘 Day 10 – CSS Layout & Page Structure
📌 Overview

This project focuses on building a clean and structured webpage layout using semantic HTML and modern CSS styling.
The goal was to practice page-level layout, spacing, reusable components, and basic responsiveness using a card-based design.

🛠️ Technologies Used

HTML5

CSS3

🎯 Concepts Practiced
🧱 Semantic HTML Structure

header, main, section, and footer

Clear separation of content areas

Improved readability and accessibility

📐 CSS Layout Techniques

Global CSS reset

Box model (margin, padding, border)

Max-width centered layout

Consistent spacing using rem units

🧩 Card-Based UI Design

Reusable .card components

Rounded corners with border-radius

Depth using box-shadow

Clean visual hierarchy with headings and spacing

🎨 Styling & Visual Design

Consistent color palette

Typography control using system fonts

Highlight badge for day indicator

Subtle shadows for modern UI feel

📱 Basic Responsiveness

Flexible container widths

Mobile-friendly spacing

Layout adapts to smaller screens

🔧 Key CSS Features Used

box-sizing: border-box

box-shadow

border-radius

max-width

rem units

Media queries (basic)

Reusable class selectors
